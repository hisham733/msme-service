# D26 — Report input, versions and date buckets

## Rule

1. **Report input is the live archive.** The Report Manager reads
   `config.REPORT_ARCHIVE_DIR` (default `all_emails/`; `/app/all_emails` in
   Docker), not the legacy `emails/` test store. `FILTER_ARCHIVE_DIR` still
   overrides a single root.
2. **One version per subject.** Folders whose names differ only by `_1`, `_2`,
   ` 3`… are one group. The report uses the keep-map entry in
   `docs/archive-versions.json`, else the newest folder with an article `.md`.
   Empty copies never win.
3. **The archive is split by received date** (cutoff **2026-10-15**):
   `received-2026-10-15-and-above/` (40) and `received-2026-10-14-and-below/`
   (111). Older copies live in `_duplicates/` (47 folders); folders with no
   article live in `_no_article/` (12). `_duplicates/`, `_no_article/` and
   dot-folders are never read by the report or the ready list.
4. **Nothing was hard-deleted.** Every move is recorded in
   `/tmp/opencode/reorganize_archive.json`; the tool is reversible by moving the
   folders back.
5. **The Report Manager has an archive-folder selector**: `All folders` (151),
   `received-2026-10-15-and-above` (40), `received-2026-10-14-and-below` (111).
   The choice is carried by `/report/run` and by the Excel RUN link, and is
   written into the report file name (`…-all-…`, `…-10-15-above-…`,
   `…-10-14-below-…`) and `report-runs.jsonl`.

## Why — measured

The report previously walked `emails/`, which holds 24 live articles plus 43
test/published subfolders — only **28 of 141** ready rows. `all_emails/` is the
live archive: 210 folders → 158 base names → 151 with an article.

After the split and version cleanup:

| Check | Before | After |
|---|---:|---:|
| Report input | `emails/` (113 rows) | `all_emails/` (**151** groups) |
| Duplicate versions in a run | yes | **0** (31 groups collapsed) |
| Ready rows with an openable article | 140/141 | **140/140** |
| Default report range (`since=2026-10-05`) | n/a | **114 rows** |
| Folder selector | n/a | **All 151 · 15+ 40 · 14- 111** |
| Date buckets | flat | 40 above · 111 below |

One ready row (id **338**, the Malay `EKSPORT-MALAYSIA…` copy) was set
`readyToFilter=false` because its article moved to `_duplicates/`; the kept
English copy is row **371**.

**Tests:** `python3 -m unittest tests.test_report_versions -v` → **10 pass**;
`tests.test_collect_select` → **15 pass**. A fake-Jev smoke run of `_do_report`
over the live archive returned **151 groups / 114 dated rows / 0 duplicates**
and wrote the new `versions` sheet.

## Rollback

Move the folders named in the manifest back to `all_emails/`, delete
`docs/archive-versions.json`, and set `REPORT_ARCHIVE_DIR=emails` (or remove the
`all_emails` default). Re-open `T-015` if the report must read the legacy store.
