# D24 — Collect, then select

## Rule

1. **Collect first.** Every email run gathers all available sources before an article is chosen:
   - all attachments (every PDF/DOCX text; all standalone images);
   - the linked Google Drive folder/file/Doc, OneDrive share and Box kit (the first eligible link
     per provider; every document inside a kit);
   - every article-like public web page linked in the email, up to 3 (Cision `/r/…` newsrooms
     included);
   - remote `<img>` photos/logos in the HTML body and direct asset links.
2. **Then select.** The fetched texts become one candidate pool with provenance (`source`, `name`,
   `url`, `text`). The extract AI sees the email body plus the top candidates (release/subject ranking,
   capped) and returns `chosenCandidate`; `articleSource` follows that choice. Source priority no longer
   decides the article in advance.
3. **Media is classified by dimensions, never by file size.** `BODY_IMAGE_MIN_BYTES` is a 512-byte
   sanity floor, not a 10 KB media gate. A 250×87 / 8.6 KB logo is a logo; a 1×1 tracker still fails
   the 200 px logo floor.
4. **A blocked source is not fatal.** A refused Drive/Box fetch keeps its reason in the stages, but the
   run is `needs_human` only when no candidate/body article remains.
5. **Link-guard.** A link returned by the decide AI is followed only when `normalize` also saw it in the
   email; short/branded links are used after their resolved destination appears in `linksFound`.

## Why — measured

Finnfund / EVF (`1a0efb123aeb2679`) was article=true, subject 100, but `hasPic/hasLogo=false`:
the HTML body carried a **250×87 / 8,662-byte Finnfund logo** and a 100×55 thumbnail. The old
`BODY_IMAGE_MIN_BYTES=10000` rejected both as `too_small` before classification, so no media was
counted. The linked Cision release page also holds an **800×440 photo (39,394 B, classified `photo`)**
and the logo, but the web fallback never ran because the body was a full release (>2,500 chars) and
`is_article_url` did not recognise `news.cision.com/…/r/…`.

After D24 (live run `e80724f3-…`, row **368**): body logo counted, Cision 800×440 photo counted,
`hasArticle=true`, `hasPic=true`, `hasLogo=true`, subject 100, **`readyToFilter=true`**. Regression
sample: i-City (row 369, ready, 98), Anak Sulung (row 370, still not ready — no media), Malaysia's
exports (row 371, ready, 100) unchanged in readiness. Totals: **149 emails · 132 ready · 17 not
ready · 11 asks**.

## Rollback

Restore the 10 KB body-image floor and the old web gate (no web fetch when the body is a full release),
and stop passing `candidates` to `extract.extract`.
