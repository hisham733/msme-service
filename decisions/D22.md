# D22 — Shared-drive support

## Rule

Every Drive folder listing and file download uses `supportsAllDrives=True` (and
`includeItemsFromAllDrives=True` for `files.list`). A folder link whose metadata has a `driveId` is a
**shared drive**; without these flags the API returns an empty list even when the folder has files.

## Why — measured

i-City `1a13a4d236120ae4`: folder `1AXJ…` has `driveId: 0AMnBpjEPxFL7Uk9PVA`. Without flags:
`files.list` → **0 files** → “empty folder”, no article. With the flags: **4 files** — `Photo.png`
(15.4 MB), `Photo Caption.docx`, release PDF (304 KB), release DOCX (2.45 MB). After the fix, live run
`ed396fdb-…` → `hasArticle=true`, `hasPic=true`, subject 99, `readyToFilter=true`.

**Rollback.** Remove the flags; shared-drive folders become invisible again.
