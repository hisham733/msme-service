# D16 — Stronger release selection

## Rule

1. **Prompt:** `siaran akhbar` / `siaran media` means **press release** and must be selected, not ignored;
   `laporan` (Malay report) is the report to ignore. (The old prompt wrongly listed "siaran" as an ignore
   word.)
2. **Kit picker:** choose by **name score + first ~1,200 chars**:
   - name: +100 release words, −100 speech words, +10 English;
   - text: +50 release marker (`for immediate release`, `nota kepada editor`, `siaran akhbar`, `kenyataan
     media`…), +15 dateline, +5 `About …`, −50 speech (`teks ucapan`, `opening address`, `remarks`…),
     −20 report (`executive summary`, `methodology`, `appendix`, `figure N`).
   - Fallback only when no score is positive: English names, then longest text.

## Why — measured

HARI EKSPORT: release DOCX (6,150) vs speeches (11,023 / 10,350) — name+text now picks the release.
APAC OneDrive: release PDF vs the CEO report — name+text picks the release.
Synthetic: `document.pdf` with "FOR IMMEDIATE RELEASE + dateline" beats `report.pdf` ("Executive Summary,
Methodology"); `Siaran Akhbar - Program PMKS.docx` beats `Laporan Tahunan 2026.pdf`.

**Rollback.** Revert to name-only/old prompt; the speech/report can win again.
