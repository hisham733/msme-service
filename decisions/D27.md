# D27 — Versioned receive prompt packs

## Rule

1. **v0 = the base prompt files** (`prompts/<name>.txt`), unchanged.
2. **v1 = the new packs** for the three row-shaping jobs:
   `decide_prompt.v1.txt`, `extract_prompt.v1.txt`, `verify_prompt.v1.txt`.
3. `config.load_prompt(name, version=...)` reads `<name>.<version>.txt` when it exists,
   else falls back to the base. `PROMPT_VERSION` (env) selects the default; empty = base/v0.
4. The pipeline passes `prompt_version` through `process_email` / `process_model` /
   `_run_pipeline` → decide/extract/verify. The harness passes it explicitly.
5. **Deterministic guards remain in both versions**: link-guard, media dimensions,
   `_finalize`, `readyToFilter` recomputation, checklist contract, archive naming.
6. **v1 is live** (`PROMPT_VERSION=v1` in `docker-compose.yml`, switched 2026-10-24).
   Rollback: set `PROMPT_VERSION=v0` (or remove it) and rebuild.

## Why — measured

Harness: `tools/prompt_eval.py` rebuilds archived emails from `all_emails/` +
their checklist rows, runs the **real pipeline** in dry-run with a fake Gmail service,
and compares v0/v1. No archive/Sheet/DB write.

**Two 6-email runs (DeepSeek `deepseek-flash`), after the verify-prompt fix:**

| Run | v0 ready / flags | v1 ready / flags | v0 text / tokens | v1 text / tokens |
|---|---|---|---|---|
| post-fix | 6/6 · 34/36 | **6/6 · 34/36** | 0.987 · 76,555 | **0.970 · 67,099 (−12.4%)** |
| first | 6/6 · 34/36 | **6/6 · 34/36** | 0.969 · 82,868 | **0.991 · 75,211 (−9.2%)** |

- **No ready/flag regression** in either run. Text similarity is 0.97–0.99 for both; the
  order flips between runs (normal model variance). **Token saving is consistent: 9–12%.**
- The only flag mismatch is one case's `hasPic` + `hasLogoInArticle` in **both** versions;
  it comes from the reconstructed archive media, not the prompt.
- **Live verification (MRCA Retail Tech Summit dry-run, v1):** row `hasArticle=true`,
  `hasLogoInArticle=true`, `hasImageInArticle=true`, `subjectScore=100`, `readyToFilter=true`,
  11,215 tokens. No archive/Sheet/DB write.
- The live run exposed a **reason/flags contradiction** ("no media" while docLogo/docPhoto were
  true). `verify_prompt.v1.txt` was tightened: docLogo → `hasLogoInArticle=true`, docPhoto →
  `hasImageInArticle=true`, and the reason must agree with the flags. The re-run reason is
  consistent.
- Cost of all A/B + live dry-runs: **$0.10** (balance $9.61 → $9.51).

**Tests:** `python3 -m unittest tests.test_prompt_eval -v` → 6 pass;
full tools suite → 44 pass.

## Rollback

Set `PROMPT_VERSION=v0` (or remove it) in `docker-compose.yml` and rebuild. The base v0
files are untouched.
