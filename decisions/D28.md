# D28 — Generic web article probe + `WEB_FETCH_MODE`

## Rule

1. **`WEB_FETCH_MODE` has three states**, read fresh per email from settings:
   - `off` — no linked web pages and no web/body/asset images. Attachments, Drive,
     OneDrive and Box still work. The stages report `skipped`.
   - `known` — only hosts/paths in `WEB_KNOWN_SITES`.
   - `probe` — known hosts plus up to **2** unknown public links per email
     (`WEB_PROBE_MAX_LINKS`). **Default.** The Config page shows this mode as **Auto**;
     the stored/API value stays `probe`.
2. **A page is an article by content, not by a hard-coded per-sender allowlist.** The probe
   accepts a page with at least **two** independent signals: `og:type=article`, JSON-LD
   `NewsArticle`/`Article`/`BlogPosting`, `<article>`, or a title plus ≥500 chars of text.
   A known host may pass with title + text.
3. **`WEB_KNOWN_SITES` is editable on `receive-config.html`**. One `host` or `host/path`
   per line/comma. A host matches every path; a path prefix matches only that section.
   An empty saved value means no known sites.
4. **All site brand logos are publisher logos.** They are recorded as `publisherLogos` in
   the `web_fetch` stage and never set `hasLogo`. A page's OG/featured or content photo
   becomes `hasPic` only if the image classifies as a photo by dimensions.
5. **Safety:** only public `http(s)` on ports 80/443; reject localhost, `.local`, private,
   loopback, link-local, reserved and multicast addresses. Tracking, social, unsubscribe,
   login, search, tag/author and asset-file links are never fetched.
6. **WebP** (`VP8 `, `VP8L`, `VP8X`) is read for dimensions and kept as `.webp`.

## Why — measured live

Email `1a1160f03ca04ae4` (Event Me Now), live dry-run inside the container:

| Mode | Web candidates | `hasPic` | `hasLogo` | `readyToFilter` |
|---|---|---|---|---|
| `probe` | PitchMyStory release | **true** | false | **true** (subject 100) |
| `known` | PitchMyStory release | true | false | true |
| `off` | none (skipped) | false | false | false |

The probe fetched 6,594 chars and the **1536×1024 WebP** featured image
(`webphoto-1.webp`, 151,524 bytes); four PitchMyStory brand images stayed in
`publisherLogos`. No archive/Sheet/DB writes (dry-run).

**Tests:** `python3 -m unittest tools.test_web_probe -v` → 7 pass; full suite **62 pass**.

## Rollback

Set `WEB_FETCH_MODE=off` on the Config page (no rebuild) to stop all linked web fetching.
`known` restricts to the list; `probe` restores the default.
