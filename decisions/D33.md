# D33 — Live ACCEPT threshold

## Rule

1. `ACCEPT_THRESHOLD` is a saved setting (`data/settings.json`), default **60**, editable
   on the filter Config page as an integer **0–100**.
2. `filter.accept_threshold()` reads it fresh for every judgement; the env/default is only
   the fallback. No restart is needed.
3. It is the weighted-score cut-off **after** the critical gates:
   - gate fires → REJECT/EDITOR REVIEW regardless of the threshold
   - no gate → weighted score ≥ threshold → ACCEPT; below → REJECT
4. The existing borderline band (45–65) still applies: a score in that band may route to
   **EDITOR REVIEW** instead of raw ACCEPT/REJECT.
5. The report runner and `/workflow.json` use the same live value.

## Rollback

Set the value back to **60** on the Config page, or remove `ACCEPT_THRESHOLD` from
`data/settings.json`; the env/default 60 applies.
