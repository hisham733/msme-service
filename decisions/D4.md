# D4 — docs/ stays flat for now — indexed, not reorganised

## Rule

`docs/` keeps its 100+ files in place and gets a hand-maintained `index.md` that classifies them by
prefix (gate definitions, filter outputs, datasets, notes). Splitting it into `docs/gate-defs/`,
`docs/outputs/`, `docs/notes/` is `todo/T-004` and must move code paths in the same change.

## Why — measured

`filter_service.py` reads and writes `docs/<name>` directly (lines 34, 331, 505, 554, 585, 631, 640,
797, 815) and `filter.py` loads `docs/jev-variants.json` (line 189). Reorganising without those edits
would break the Report Manager, Lab payloads and verdict logging.

**Rollback.** n/a — nothing moved.
