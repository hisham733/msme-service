# D5 — Filter definition docs are kept as test variants

## Rule

`docs/FILTER-LOGIC.md`, `docs/FILTER-REVIEW.md`, the older sections of `docs/ARCHITECTURE.md` and the
`docs/gates-def-*` / `original-gates.xlsx` variants stay **as written**. They are deliberately kept to
test different article/definition variants — a future session must **not** rewrite them to match the live
battery, and must not delete a variant it thinks is stale.

The **live** truth is the running service: `GET localhost:8900/filters.json` (3 gates + 11 scores,
weights 100 on 2026-10-21). A doc disagreeing with it is not an error to fix unless the user asks.

## Why — measured

`todo/T-002` proposed reconciling two stale descriptions with `/filters.json`. The user rejected the
reconciliation because the differing definitions are the test material for variant runs. The measured
mismatch (docs: 6 gates + 8 scores; live: 3 + 11) is therefore **intentional**, not a defect.

**Rollback.** Delete this decision and re-open `T-002` if the variants are no longer needed.
