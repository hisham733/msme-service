# D38 — Package layout

## Rule

1. **All runtime code lives in `msme/`**; the repository root keeps only `run.py` as the launcher.
2. **Stage packages** group the code by pipeline stage: `msme/receive/`, `msme/filtering/`,
   `msme/repurpose/`, and `msme/legacy/` (the old `:8898` API, kept for tests).
3. **Shared modules** (`config`, `db`, `creds`, `settings_store`, `auth`, `connection_test`,
   `llm`, `deepseek`) sit at the package root; `msme/combined.py` is the one ASGI entrypoint.
4. **`msme/paths.py` resolves every runtime directory** (`ROOT`, `STATIC`, `DOCS`, `PROMPTS`,
   `DATA`, `CREDS`, `ARCHIVE`, `LEGACY_ARCHIVE`, `REPURPOSE_INBOX`, `REPURPOSE_SITE`) from the
   package location, never from the current working directory. Each keeps its environment
   override; a relative value is anchored at `ROOT`.
5. **Imports are absolute package imports** — `from msme.receive import pipeline` — never flat
   `import pipeline`. No compatibility shims remain at the root.
6. **The entrypoint does not move**: Docker still runs `python run.py`, which starts
   `msme.combined:app` (single uvicorn worker).
7. **Tests live in `tests/`** and run with `python3 -m unittest discover -s tests -p 'test_*.py'`.
   One-off developer scripts live in `tools/`.
8. **Filename renaming is out of scope**: files keep their names, so headers, registers and
   historical replies stay readable.

## Why — measured

Before the change: 45 root `.py`, 214 import lines naming root modules (168 top-level + 46
lazy inside functions), ~30 path sites built from `dirname(__file__)`, 3 dynamic
`__import__` calls, 13 test modules under `tools/`, and a Workflow Lab purpose map that
scanned the flat root. That layout only worked when the process started in the repo root.

After the change: 37 modules under `msme/`, 7 one-off scripts in `tools/`, 13 tests in
`tests/`, one root module (`run.py`), 209 import lines rewritten, paths centralised, the
purpose map walking the package, **149 tests pass**, `ruff check` clean, Docker image builds
and `/health` answers.

## Supersedes

Only the "root `*.py`" wording in `README.md`, `AGENTS.md` and `.claude/rules/msme-service.md`.
It does **not** touch `D4` (docs stay flat) or `D5` (filter variants are never reconciled or deleted).
