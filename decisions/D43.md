# D43 — N-1 gallery matching and the usable-logo floor

## Rule

1. **Option B — usable logo.** The N-1 trigger uses `hasUsableLogo`, not the factual `hasLogo`:
   a logo counts only when it is **vector** or its max side is **≥ `BODY_LOGO_MIN_DIM` (200 px)**.
   A 40×20 letterhead icon or a `logo.png` under 200 px does not suppress the gallery; if the
   gallery also misses, the article is not ready and the ask email is sent. The checklist may still
   show `hasLogo=true`; readiness uses the usable flag.
2. **Hybrid priority ladder** (§6 of the spec), first match per brand:
   1. sender domain in `domains` → hit,
   2. exact alias in the subject/headline → hit,
   3. exact alias in the sender display name → hit,
   4. exact alias in an attachment filename **and** the body → hit,
   5. exact alias in the first `GALLERY_BODY_LEAD_CHARS` (600) chars **and** ≥ 2× in the body → hit,
   6. fuzzy ≥ 0.88 in the subject/display name → hit.
3. **Scores** are 100/95/90/85/80/fuzzy×100. If the top **two brands** are within **10 points** →
   **miss** (tier 7). A miss only sends the ask email; a false hit would publish the wrong logo.
4. **Store:** `data/gallery/index.json`; N-1 matches only `active` `logo` entries. Files resolve
   inside the gallery (`..` and absolute paths rejected); missing/corrupt/oversized files are an
   error, never a failed run.
5. **Known agencies** (`GALLERY_AGENCY_DOMAINS`, default `cision.com, mediaoutreach.com,
   vritimes.com`) are never in a brand's `domains` list.
6. **Pipeline:** between `logo_scan` and `verify`; a hit adds `gallery_logos[...]`, sets
   `hasLogo=true` + `hasUsableLogo=true`, archives the file and records `stages["gallery"]`.
   `GALLERY_ENABLED=false` disables it.

## Why

The gallery fills the missing-image case before the ask email. Option B prevents a tiny icon or a
`logo.png` from silently suppressing the gallery, while keeping the factual `hasLogo` on the
checklist. The hybrid ladder is conservative: the domain map is strongest, and an ambiguity guard
makes the wrong-logo case a safe miss.

**Amended 2026-11-07 (same day):** tier 5 dropped the "known agency" sender gate and now requires an
exact alias in the first 600 chars **and** ≥ 2× in the body, any sender. The agency gate missed
forwarded editor emails (`editor@malaysiasme.com.my`) whose release text names the brand (e.g. the
Xendit 6-market release). The 600-char lead keeps the tier strict: a brand mentioned only later in
the body still misses.

## Rollback

Set `GALLERY_ENABLED=false` (env or `data/settings.json`); the pipeline records `gallery: skipped`
and the ask email continues.
