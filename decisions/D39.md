# D39 — docs/ grouped by topic

## Rule

1. **Non-code documentation is grouped by topic**:
   - `docs/workflow/` — architecture, workflow, receive examples, source routing, code map;
   - `docs/filter/` — Jev rules, gate definitions, comparisons; `docs/filter/experiments/` for the
     superseded variant runs;
   - `docs/meetings/` — one folder per meeting date;
   - `docs/operations/` — runbooks, reports, sender asks, token cost;
   - `docs/receive/` — receive-stage feedback;
   - `docs/reference/` — client source material and the future MySQL schema.
2. **Files the code reads or writes by name stay flat at `docs/` root** (`D4` still applies):
   `jev-variants.json`, `archive-versions.json`, `article-records.json`, `artical.json`,
   `negative-dataset.json`, `email-dates.json`, `sme-reject-6-10.json`,
   `filter-variants-report-10.json`, `filter-variant-separation.json`, `published-index.json`,
   `published-dataset.json`, `gates-def-*.xlsx`, `report-runs.jsonl`, `FILTER-REPORT-*`,
   `PROMPT-EVAL-*`, `DRIVE-FOLDER-4-*`, `jev-way-learning.md`.
3. **New report outputs keep landing at `docs/` root** — the code writes them there.
4. Moving a code-read file is a code change: update `msme/filtering/*`, `msme/receive/archive_layout.py`,
   `static/testfilter.html` or `tools/*` in the same change and re-run the tests.
5. **`D5` is unchanged**: `FILTER-LOGIC.md`, `FILTER-REVIEW.md`, `gates-def-*` and
   `original-gates.xlsx` stay as test variants (now under `docs/filter/`).

## Why — measured

Before: 107 entries in `docs/` (files + folders), ~6.7 MB, mixed runbooks, gate variants, report
outputs, meeting notes and experiment runs in one flat list. `docs/INDEX.md` had to classify them by
prefix because folders were not allowed (`D4`).

After: 6 topic folders plus the code-touch files at the root. The app is unchanged — every
code-read path still resolves — and `docs/INDEX.md` now maps the folders.

## Supersedes

The "keep docs flat" part of `D4` only. `D4`'s rule that **code-read files stay flat** remains in force.

## Rollback

Move the folders back to `docs/` root; no code change is needed for the non-code files.
