# D19 — Resolve short media-kit links

## Rule

If `decision.linkToFetch` is not already a Drive/OneDrive/Box URL, the pipeline resolves its redirect once
(browser UA, 8-hop cap in normalize). If the final URL is a Google Drive folder/file or OneDrive share,
that final URL is used for the normal kit/file path. This prevents the redirect cap from hiding a media kit
behind a `bit.ly`/branded link.

## Why — measured

EAP `1a11435942816b83`: `https://bit.ly/mem-oct2026` resolves to
`drive.google.com/drive/folders/1Pn55…`. A re-run missed the kit because the link was not among the resolved
`linksFound`; the row had no article. After the fix the kit fetched:
`Macro Poverty Outlook - Malaysia - October 2026.pdf` + `Media Advisory …pdf`; the report was selected,
subject 78, embedded logo → `readyToFilter=true` (row 363, run `356dfd62-…`).

**Rollback.** Remove the extra resolution; short links can be missed again.
