# D14 — Photos vs logos stay split (attachment dimension rule deferred)

## Rule

`hasPic` means a real photo; logos stay `hasLogo`; icons/tracking pixels are skipped. When implemented, an
image **attached** to the email counts by its **dimensions** (like D7 body images), not the 1 MB rule, so
the three APAC 1664×1175 photos (115–144 KB) would be `hasPic=true`. Body-only images do **not** set
`hasImageInArticle` (that stays for images inside a PDF/DOCX).

ready by accident. The OneDrive press release (D15) now also supplies deterministic doc logo/photo evidence,
so readiness is stable even with this deferred.
