# D36 — MSME Editor page

## Rule

1. `/editor.html` is the **end-user editor** page; the dark `/checklist.html` stays the
   **Operations** page.
2. The editor page lists **every received email** (one current item per email/thread) and
   keeps older re-runs in each item's **Version history**. It shows **20 per page**, sorted by
   **last edit** (newest first), with Previous/Next paging; the counts remain whole-database.
3. Each item names the **stage it stopped at** and the reason:
   receive, readiness, editorial check, draft, or publish.
4. The detail panel shows the stage timeline, article flags, filter result, repurpose status,
   the exact failing draft rules, and links to the local draft and filter history.
5. **Publish / Send is visible but disabled** until a real uploader exists; local draft pages
   are served at `/repurpose-site/...`.
6. The page is **desktop-first** and uses a **light theme**; status uses icon + text, not colour
   alone. Old versions are grey **Previous version**, not black-on-dark.

## Why

The operator checklist is correct for debugging but too technical for an MSME editor. The editor
needs to know: did it arrive, why did it stop, what is the draft, and can I open it?
