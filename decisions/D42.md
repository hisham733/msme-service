# D42 — Cost basis

## Rule

1. A **chain** is one email id: latest receive run + latest Jev verdict + latest repurpose run.
   **All-runs spend** additionally counts every retry/re-run.
2. Rates (USD), stored as settings and editable on **Config → Cost**:
   - DeepSeek **$0.65 / 1M total tokens** (measured D27 blended rate)
   - Jev **$0.042 / 1M input tokens** (output free)
   - Gemini **$0.65 / 1M total** (fallback when the provider switches)
   - Budget/credit **$0** = the bar is hidden
3. Costs are labelled **estimated** and recomputed from stored usage; the app does not invent a
   price when a rate is 0 or a model is unknown.
4. The repurpose engine records OpenAI-style `usage` on every chat and vision call (cached images
   cost nothing) into `run.json` and `repurpose_runs.usage_json`. A run without usage shows
   **“not measured”**, never a silent $0.
5. The Cost page and `/api/costs.json` are **admin-only**. On 2026-11-07 the user removed the
   Receive/Jev tabs: `/ai-model.html` is now the **Cost** page, and its table is server-paginated
   **20 rows per page** (`page`, `page_size`, `q`); the browser never receives every record.

## Why

`docs/operations/PROCESS-TOKEN-COST.md` measured receive/filter cost but the engine had no usage
field, so the receive → publish figure could not be quoted. The dashboard now shows both the
current per-article cost and the real historical spend (retries included), with the rates visible.

## Caveats

- Historical repurpose runs before this change have no usage.
- Jev preprocess/assist DeepSeek usage is not included in the stored verdict usage (Jev dominates).
- A vendor price change needs one Config save, not a deploy.
