## T-047 Auth + filter-config versions

Deferred until the webhook is finished.

- Local username/password login (no Google login).
- Roles: `admin` (dashboard, users, all config) and `editor` (editor page + filter config only).
- SQLite `users`, `sessions`, `audit_log`, `filter_config_versions`.
- Password hashing with stdlib `scrypt`; HttpOnly/Secure cookies; CSRF; login rate limit.
- Admin user management page.
- Every filter-config save records actor, time, before/after diff, config hash, full battery snapshot.
- Config-version history UI; admin-only restore (restore creates a new audited version).
- `/webhooks/gmail` bypasses user auth; Google OIDC only.
- Disable/bypass Cloudflare Access once app login works.

**Done when.** Admin/editor can log in, editor can change only filter config, every change is attributed and versioned, and the webhook stays public.
