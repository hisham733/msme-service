## T-014 Filter ready-list must read both emails/ and all_emails/

Receive writes to `LOCAL_ARCHIVE_DIR` (`emails/` in older runs, `all_emails/` in the live container) while
the filter's ready list indexed only `emails/`. Measured: **54 of 71** ready rows had no resolvable path,
so the Filter page could not open them even though the row said ready.

✅ **DONE 2026-10-22:** `filter_service._archived_roots()` now indexes `emails/` + `all_emails/`
(`FILTER_ARCHIVE_DIR` still wins), and `/archived/read` accepts a path under either root. The IRGCE row
now resolves to `all_emails/…/images` article. Reports (`_list_articles`) deliberately still scan the
primary root — see the note in the reply.
