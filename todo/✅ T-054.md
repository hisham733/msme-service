## ✅ T-054 Config Repurpose tab

`/config.html` now has four tabs: **Receive · Filter · Repurpose · Cost**.

The Repurpose tab edits (all applied to the next article, no restart):

| Setting | Range / default |
|---|---|
| `ENABLE_AUTO_REPURPOSE` | on/off (moved here from the Filter tab) |
| `REPURPOSE_MODEL` | default = `DEEPSEEK_MODEL` |
| `REPURPOSE_TEMPERATURE` | 0–1, default 0.2 |
| `REPURPOSE_RETRY_LIMIT` | 0–5, default 2 |
| `REPURPOSE_POLL_SECONDS` | 1–300, default 5 |

Read-only: `REPURPOSE_INPROCESS` (needs a restart), inbox/site paths, and a link to
`/repurpose.html`. `msme/repurpose/engine/config.py` reads the settings fresh in `load_config()`;
`runner._loop` reads the poll interval fresh.
