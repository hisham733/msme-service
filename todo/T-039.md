## T-039 Interactive Receive Workflow Lab

✅ **DONE 2026-10-23** — `http://localhost:8899/workflow-lab.html`

- New page `static/workflow-lab.html` + backend `workflow_lab.py` (APIRouter on :8899).
- **8 stages** (Receive · Read & clean · Choose source · Fetch content · Extract article ·
  Check media · Decide readiness · Save) with real code excerpts, plain-English explanations,
  inputs/outputs and per-stage risk notes.
- **Runnable examples** (simulated AI, instant, free): `simple_release`, `ready_release`,
  `no_article`; **replay** of the latest real run; **PDF/DOCX upload** for the media scan.
- **Workflow diagram tab** (`#chart`): auto-playing 8-stage flow with two decision branches
  (`Where is the article?` → attachment / Drive / web / body; `Ready to filter?` → ready / not ready),
  narration, a clickable plain-English detail card, the `article + media + subject > 60 = readyToFilter`
  equation and a "what happens next" panel. Controls: Play / Pause / Play again / Reset; no code/JSON
  in this view.
- **Media detail in the diagram**: a "Where is the image?" callout next to *Check media* and a
  four-flag map — **in the email** → `hasPic` / `hasLogo`, **inside the article PDF/DOCX** →
  `hasImageInArticle` / `hasLogoInArticle` — plus the logo-vs-photo dimension rule (≤300 px / wide
  strip / repeated header → logo; ≥500 px → photo; never count an in-article image as `hasPic`).
- **Per-stage details**: every stage in the walkthrough and every diagram node now has a `Details`
  list — Receive query/read rules, Read & clean stripping, Choose source link guard, Fetch caps and
  branches, Extract fallback, Media four flags, Verify formula, Save columns/archive/reply. The two
  decisions and the ready / not-ready outcomes have their own details too.
- **Live email dry-run** (Phase 2): real Gmail + real AI, `dry_run=True` — no archive, Sheet,
  reply or DB write.
- **Project code map**: every `.py` (42 files) with role, purpose, importers and a
  `NEEDED / feature / tooling / NOT RUNTIME` verdict.

**Measured:** page 200; `/api/workflow/stages` → 8 stages + 42 files; examples → rows

`python3 -m unittest tests.test_workflow_lab -v` → **11 pass**; full tools suite **38 pass**.

**Safety:** the lab never writes; one lab run at a time; code viewer is whitelisted.
