## 🟢 T-057 Human approve & publish (EDITOR REVIEW)

**Problem:** when the editorial filter returns **EDITOR REVIEW** (borderline score), the article stops:
`repurpose_export._accepted_latest()` exports only rows whose latest outcome is **ACCEPT**, so there is
no draft and "Publish: Not started". There is **no audited human override** today — only manual DB
edits or lowering `ACCEPT_THRESHOLD` globally.

**Live evidence (GOODDAY KIDSTART 4.0):** checklist 425 / filter result 32 → `outcome=EDITOR REVIEW`,
`gate=BORDERLINE`, `weighted=64` (threshold 60); the 3R gates are ~0.01 (no sensitivity issue). Ready
to publish if a human says yes.

### Proposed mechanism (recommended)

- Record the decision as a **new `filter_results` row**: `outcome=ACCEPT`, `gate=MANUAL_ACCEPT`,
  `model=manual`, verdict `{manual:true, by:<user>, at:<ts>, from:"EDITOR REVIEW", weighted}` — plus an
  `audit_log` entry (`auth.audit`).
- Because it becomes the latest result for that article, the existing export picks it up with **no
  change to `_accepted_latest`**, and it shows in the Filter history.
- In the same action: run the table-driven export → the daemon runner drafts → the site builds. The
  editor timeline moves needs-review → publishing → published.
- **Safety:** only `EDITOR REVIEW` is approvable. A `REJECT` (especially any 3R gate) stays final; the
  button never appears there.

### Open decisions (answer before building)

1. **Who can approve** — admin only (recommended) or admin + editor?
2. **Storage** — manual `filter_results` row (recommended) or a checklist flag?
3. **Treatment** — approve = normal rewrite/repurpose path (same as a real ACCEPT)?
4. **Scope** — only EDITOR REVIEW (recommended), or also an admin override of a low-score REJECT with a
   warning?
5. **Reversible** — add "Revoke approval" now or later?

### Checklist (when started)

- [ ] `POST /api/filter/approve` (admin; CSRF) — refuses a REJECT; inserts the manual ACCEPT row; audits.
- [ ] Trigger `repurpose_export.export(apply=True)` + the runner; return `{queued}`.
- [ ] Editor detail: show **Approve & publish** only when `filterOutcome=EDITOR REVIEW`.
- [ ] Filter history / editor: show `MANUAL_ACCEPT` with who/when.
- [ ] Tests: borderline approve → export picks it; REJECT refused; audit written; button hidden on REJECT.
- [ ] Live proof: publish the GOODDAY KIDSTART article through the new action.
