## 🟢 T-050 One repo · one process · one DB for repurpose

**Progress:** P0–P4 ✅ built and verified 2026-11-06 — **191 tests pass**, Docker image `msme-service:t050-20261106`, `/repurpose.html` 200. Only the physical deletion of `MSME_AI_News` waits for MG’s written OK.

**Decision to record first:** `D40` — supersede `D35` ("repurpose runs on the external
`MSME_AI_News` engine"). The engine becomes a vendored part of `msme-service`, imported in
process; `MSME_AI_News` stays only as the upstream record until the cut-over, then the local
folder is deleted.

**Locked choices**

1. **One repo**, **needed set only** (runtime + skills + tests + docs + referenced decisions +
   AGENDA). Do **not** merge MG's `Files_from_MSME/`, `analysis/` evidence, `corpus/`, `Jev/`,
   `tools/`, `roadmap/`, or his registers.
2. **One process**: FastAPI + a daemon engine thread on :8899; no subprocess, no :8765.
3. **One DB**: `data/msme.sqlite3`; `run.json` stays as the folder contract and is mirrored
   into the DB.
4. **UI**: drop the engine dashboard; add `/repurpose.html` + `/api/repurpose/status`.
5. **Deps**: add `Pillow` and `PyMuPDF`.

### Target layout

```
msme/repurpose/
  repurpose_export.py      # ACCEPT -> inbox + repurpose_exports table
  runner.py                # NEW: build_cfg, run_folder, worker_loop, status
  config.py                # NEW: engine defaults + paths + key
  engine/                  # vendored pipeline + skills/ + dlw_shell/fonts/
tests/repurpose/           # adapted engine tests + runner/DB tests
docs/repurpose/            # guides, contract, referenced decisions, UPSTREAM.md
data/msme.sqlite3          # ONE DB
```

### One DB

| Table | Holds |
|---|---|
| `repurpose_runs` | folder, checklist_id, filter_result_id, status, model, started/finished, error, `run_json`, draft/site paths |
| `repurpose_exports` | checklist_id, filter_result_id, dest, article/config hash, weighted, exported_at, status |
| `repurpose_events` | run_id, stage, status, detail, timestamp |

- `manifest.write` keeps writing `run.json`; the runner mirrors it into `repurpose_runs`.
- `repurpose_export.py` writes `repurpose_exports`; retire `data/repurpose_export.json`.
- `dashboard.py` / `editor_data.py` read the DB.

### Risks

- **Irreversible deletion** — the cut-the-cord test is the gate.
- **Upstream drift** — the vendored copy is a fork; `UPSTREAM.md` records the commit.
- **Deps** — Pillow + PyMuPDF add ~30–50 MB to the image.
- **Fonts** — `repurpose_site` currently has none; the seed step fixes it.
- **Ownership** — MG's code now lives here; written OK before deleting.
- **Long drafts** — must run in the thread, never block a request.
