## T-027 Google-native non-Doc files are not fetched

`drive_fetch.fetch_file` exports a Google **Doc** as text, but any other Google-native type
(`presentation`, `spreadsheet`, `drawing`, …) returns `unsupported_google_file` → the run is
`needs_human`. The MATRADE press release is shared as a Google-native file with `canDownload=true` and
size 0.

✅ **BUILT 2026-10-22 (unit-tested):** `drive_fetch.fetch_file` now exports Docs → text,
Slides/Sheets → PDF, Drawings → PNG; fake-Drive test passes. Deployed in `google-native-20261022`.

✅ **CLOSED 2026-10-22:** export support is built/unit-tested and deployed; the MATRADE link turned out to be
a **folder** (handled by `D18`/`T-029`), so no live native-file case remained to test.
