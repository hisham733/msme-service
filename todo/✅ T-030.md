## ✅ T-030 Dashboard status used an older run

`/api/logs` returns runs newest-first, but `loadStatusMap` assigned every log to the same email key, so the
**oldest** run (`needs_human`) overwrote the newest `success`. The checklist row itself was ready.

✅ **DONE 2026-10-22:** keep the **first (newest)** run per email; only the latest checklist row per email
shows the current status, older duplicate rows show **superseded**; `/checklist.json` now carries `id` and
`created_at`. Deployed in `msme-service:dashboard-status-20261022`.
