## ✅ T-052 In-app Google reconnect

**Flow:** Config → Receive → **Google account** card:

1. **Open Google consent** → `GET /api/google/reauth` returns the consent URL built from
   `creds/gmail.json` (client id only; the secret never leaves the server).
2. Sign in as the newsroom account and approve Gmail/Drive/Sheets.
3. The browser fails to load `http://127.0.0.1:8080/?code=…` (normal) — copy the whole address.
4. Paste it into the card and press **Finish reconnect** → `POST /api/google/reauth` exchanges
   the code, rewrites `creds/{gmail,drive,sheets}.json` atomically and renews the watch.

**Security:** admin-only (not in `EDITOR_GET`), CSRF-protected, tokens are never returned or
logged. `creds/` is now mounted writable in `docker-compose.yml` so the in-container exchange can
write the files.

**Proof:** `tests/test_google_oauth.py` (6 tests, mocked token endpoint, no network) ·
`/api/google/reauth` = 401 without a session · full suite 241 tests.

**Still the user's step:** actually completing the consent in a browser (needed for `T-028` and
the `emails` backfill).
