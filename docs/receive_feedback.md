### What each class means

- **SKILL_RIGHT** — the skill chose what TARGET-class practice says
- **SKILL_WRONG** — a usable asset was there and the skill chose badly — this project's fix
- **RECEIVE_GAP** — the published picture is not in the pack at all — the partner's fix
- **RECEIVE_WRONG** — the asset is in the pack but mangled — the partner's fix
- **NO_PRESS_PAGE** — no published page to compare against yet — wait

## 4. Method (how to reproduce)

```powershell
python tools\scrape_msme.py            # published pages (reads the batch's own _LINKS.md)
python tools\fetch_featured.py         # TARGET's featured image per article
python -m pipeline.harvest --all       # mine the supplied .pdf/.docx
python tools\imgtruth.py --inbody      # ground truth: which supplied file TARGET published
python tools\imgtag.py                 # vision tags (cached; only new files cost)
python tools\imgdata.py                # the scored dataset + the in-pack verdict
python tools\imgeval.py --batch B3 --detail
python tools\receive_audit.py --batch B3
```

`in pack` = pixels matched (a real file carries that picture) or brand matched (the same organisation's mark of the same kind is present, e.g. a logo rendered out of a supplied PDF letterhead). Both mean the receive stage delivered; only the first means a publishable file exists, which is why the class is still `RECEIVE_GAP` when only the brand arrived.
