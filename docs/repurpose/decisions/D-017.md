# D-017 — Build the handoff; never hand-copy folders

## Rule

`python tools\build_export.py` produces `export\MSME_AI_News_handoff\` (+ optional zip) from an explicit
include list. It excludes `.env`, `config.local.json`, `Files_from_MSME\`, `corpus\`, `analysis\`,
`todo\`, `session_analysis\`, `tools\`, `pipeline\devtests\`, `DLW\images\` and `DLW\articles\`; it
includes `partner_handoff\`, `meeting_notes\` (with `AGENDA.md`), `COLLABORATION.md`, the hooks, CI,
`decisions\` and `roadmap\`. It writes `EXPORT_SOURCE.txt` (commit + uncommitted count) and a per-file
sha256 manifest. `--check` builds into a temp dir and fails on a secret pattern, a client folder, a file
over 5 MB, or a missing required file.

## Why — measured

The old `GUIDE.md` §9 said "copy `pipeline\` minus `devtests\`, `DLW\`, the skill folders, `config.json`,
`.env.example`". That is a list a human must remember, and it cannot notice a new file. The first built
export was **93 files / 608 KB**, and `--check` proves the exclusions rather than asserting them. The
export also carries the **synthetic** demo (`partner_handoff\demo_releases\`) so the integration test never
needs client material.

**Rollback.** The builder only writes under `export\`; deleting that folder reverts it.
