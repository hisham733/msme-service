# D-008 — Graph images are never the key visual

## Rule

When an image file received with a release is deemed a **graph** (chart/diagram/infographic), that
file **cannot be used as the key visual** — never the featured image, never the index-card image,
never the article cover. It may still appear **in-body** where the article cites it. It is never a
candidate on the featured ladder.

## Why — measured

MSME confirmed the rule to EF; MG logged it 2026-10-22 with the G1–G3 goals. It closes a gap rather
than contradicting anything: the `msme-image-select` ladder (D-003) runs people → logo → event-visual
→ product → HOLD (SKILL.md rules 1–2), so a graph was already never a rung — no past decision
conflicts. The vocabulary gains the `graph` class explicitly.

## Implementation note (this build)

The two `SKILL.md` files are already delivered to the partner (Phase 4) and are not edited now; the
rule is enforced where the build lives — the upload engine's validator (T-011) fails a draft whose
featured image classifies as `graph`. `graph` joins the skill's classification vocabulary (SKILL.md
step 1) at the next skill revision.

## Rollback

Remove the engine's graph-never-featured check (one line in the validator); the ladder is unchanged.
