## 1. What changed (msme-service)

- **Receive status** (`/editor.html`): `Not ready to filter` is replaced by
  **`no article`** when `hasArticle` is false, or **`no media`** when the article exists but
  `hasPic` / `hasLogo` / `hasImageInArticle` are all false. The chip reads
  `Receive: no article` / `Receive: no media`.
- **Publish status**: the old `Draft:` chip and `Draft needs attention` are now
  **`Publish: not started`**, `Publish: in progress`, `Publish: ready`, `Publish: published`,
  **`Publish: issue`**. The raw `Draft: queued` line was removed from the list meta.
- **Filter status**: `Needs editor review` is replaced by a plain label:
  - **`fail 3R`** when the reject gate is one of `ROYAL_RESPECT`, `RELIGIOUS_RESPECT`,
    `RACIAL_RESPECT`;
  - **`not relevant`** when the weighted score is below the live `ACCEPT_THRESHOLD`;
  - `needs review` only for an ambiguous gate above the pass mark;
  - `check failed` / `accepted` otherwise.
- **Duplicate “Why”**: the section-level `Why:` boxes under Receive and Filter are removed;
  only the top **“Why it stopped”** remains (and the single Publish reason box).
- **WordPress Publish / Send** is now a link to
  `http://localhost:8765/dlw/index.html` (new tab). The “Engine dashboard” link stays.
- **Filter history**: the critical-gate table has a **Jev result** column next to each gate:
  `YES 0.990 · defect 0.010 · pass/fired`, using the stored per-gate defect and the battery
  threshold.
- **Rule-editor label/links removed** from `/config.html`: `Rule editor`, `filter-config.html`,
  `Open full filter rule editor ↗`, `filter history ↗`, `battery JSON ↗`. The embedded rule
  editor iframe remains (only the label/link row was removed).
