Where is the image? — the four media flags

The same picture gets a different flag depending on where it lives.

In the email

  • Attached photo → hasPic
  • Attached logo file → hasLogo
  • Body image / asset link → hasPic / hasLogo
  • Drive / OneDrive / Box / web image → hasPic / hasLogo

Inside the article PDF/DOCX

  • Embedded photo → hasImageInArticle
  • Header / embedded logo → hasLogoInArticle
  • Never counted as hasPic

Logo or photo? (by dimensions)

≤ 300 px, a wide/short strip, or a repeated header/footer → logo. A large image (≥ 500 px) → photo. A header image in a DOCX is always a logo.

When is an email ready?

article found+ photo or logo+ subject match > 60= readyToFilter

If one of the three is missing, the row is not ready and the filter does not run.

What happens next

Ready rows go to the Filter stage, where Jev applies the editorial rules. Not-ready rows stay back for a reply or a human check.

Plain-English glossary

Normalize

Turn the raw email into a clean package: subject, sender, body without the cover note, attachments and links.

Attachment

A file sent with the email (PDF, DOCX, image). The pipeline downloads it and reads its text.

Media kit

A Drive/OneDrive/Box folder with the release and photos. The pipeline fetches it when the email links to one.

Candidate

One fetched source (attachment, Drive doc, web page, email body) that might be the article. The extract AI picks one.

Deterministic

Code that does not call an AI — for example, reading image dimensions to tell a logo from a photo.

readyToFilter

True only when there is an article, some media (photo or logo), and the subject matches the headline above 60.

needs_human

The source could not be fetched (view-only Drive file, blocked page). The run stops instead of guessing.

Archive

The local folder for one email: article.md, images/ and originals/. The filter and reports read it.

Live email dry-run

This uses the real Gmail message and the real AI provider. It does not write the archive, Sheet, database or send a reply. It may take 1–3 minutes and spend AI tokens.
